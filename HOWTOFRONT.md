# Инструкция по работе с фронтендом

## Структура проекта
- Вся фронтенд-часть находится в папке `web/`.
- Основные страницы: Home, Game, Profile.
- Для управления роутингом используется React Router.
- Аутентификация реализована через запрос к серверу с передачей `initData` от Telegram.

## Как запускать фронтенд
1. Перейдите в папку `web/`.
2. Установите зависимости:
   ```
   npm install
   ```
3. Запустите проект:
   ```
   npm start
   ```

## Как вносить изменения
- Для добавления новых страниц создайте компонент в папке `src/pages/` и добавьте маршрут в `src/App.js`.
- Для изменения логики аутентификации — редактируйте `src/auth.js`.
- Для работы с API используйте функции из `src/api.js`.

## Аутентификация
1. При запуске Mini App Telegram передает в приложение строку `initData`.
2. В компоненте `App` или отдельном хуке отправьте запрос на сервер:
   ```js
   fetch('/api/auth', {
     method: 'POST',
     credentials: 'include',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({ initData })
   })
   ```
3. Сервер проверяет подлинность, создает пользователя (если нужно), возвращает access- и refresh-токены, которые устанавливаются в http-only secure cookies.
4. Для проверки авторизации используйте запросы к защищённым эндпоинтам.

## Рекомендации
- Все секреты (bot_token и др.) хранятся только на сервере.
- Не храните токены в localStorage или JS — только http-only cookies.
- Для обновления токенов используйте refresh endpoint на сервере.

## Разработка
- Используйте современные хуки React.
- Для стилей можно использовать CSS-модули или styled-components.
- Для запросов — fetch или axios.

**Docker / env**: как подставлять секреты

- В `api/` есть `docker-compose.yml` — он поддерживает подстановку переменных окружения из файла `api/.env`.
- Скопируйте `api/.env.example` в `api/.env` и заполните `BOT_TOKEN`, `JWT_SECRET` и при необходимости `POSTGRES_CONN`.
- Пример (в папке `api`):
```powershell
copy .\.env.example .\.env
# отредактируйте .env и затем запустите
docker compose up --build
```
- В `docker-compose.yml` переменные используются как `${VAR}` с разумными значениями по умолчанию. Для локальной разработки `COOKIE_SECURE=0`, на проде установите `COOKIE_SECURE=1`.
